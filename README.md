# Twin Paradox Visualizer

Interactive Minkowski spacetime diagram that visualises the twin paradox from special relativity.

## Tech Stack

- React 19 + TypeScript
- D3.js for the spacetime diagram
- Tailwind CSS v4
- Vite

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production Build

```bash
npm run build
npm run preview   # preview the build locally
```

## Deploy to Vercel

```bash
npm i -g vercel   # install Vercel CLI (once)
vercel             # follow the prompts
```

Or connect the GitHub repo at https://vercel.com/new — Vercel auto-detects Vite.
